# 🚀 Hamza Eshtiba - Modern Full-Stack Portfolio & CMS

موقع معرض أعمال متكامل وبوابة شخصية تفاعلية للمهندس حمزة اشطيبه، مع لوحة تحكم إدارية مدمجة (CMS Dashboard) لإدارة المشاريع والخدمات والمهارات وتخصيص نصوص الموقع بالكامل باللغتين العربية والإنجليزية.

## ⚡ نظرة سريعة على الميزات
- 🌐 **معرض أعمال متكامل:** أقسام تفاعلية (Hero, About, Skills, Projects, Services, Experience, Contact).
- 🎛️ **لوحة تحكم إدارية (Admin CMS):** إدارة كاملة للمشاريع والرسائل الواردة وتخصيص محتوى وأقسام الموقع دون تعديل الكود.
- 📄 **مولّد السيرة الذاتية التفاعلي:** معاينة السيرة الذاتية وتصديرها كملف PDF عالي الجودة بضغطة زر عبر `html2pdf.js`.
- 🌓 **مظهر ثنائي ولغات متعددة:** دعم كامل للوضع الليلي/النهاري، واللغتين العربية والإنجليزية مع اتجاه الكتابة RTL/LTR.
- 🔒 **أمان متقدم:** حماية بـ JWT، تشفير Bcrypt، حماية الترويسات بـ Helmet، والحد من معدل الطلبات بـ Rate Limiting.
- ☁️ **جاهز للنشر السحابي:** مهيأ كـ Monorepo للنشر على Vercel أو Render.

## 🛠️ التشغيل السريع محلياً (Quick Start)

### 1. تشغيل الواجهة الخلفية (Backend)
```bash
cd backend
npm install
npm run seed     # لإنشاء الحساب الإداري الافتراضي والبيانات الأولية
npm run dev      # يعمل على http://localhost:5000
```
> بيانات المدير الافتراضية:
> - **البريد الإلكتروني:** `admin@hamzaeshtiba.dev`
> - **كلمة المرور:** `AdminPassword123!`

### 2. تشغيل الواجهة الأمامية (Frontend)
```bash
cd frontend
npm install
npm run dev      # يعمل على http://localhost:5173
```

للاطلاع على كافة التفاصيل والـ APIs والشرح المعماري المخطط، يرجى مراجعة [PROJECT_DOCUMENTATION.md](./PROJECT_DOCUMENTATION.md).
